# パワプロアプリ攻略ベース（公開用サイト）

公開先は GitHub Pages（main ブランチの /docs フォルダ）。

## しくみ
- `src/` … 元の部品（`layout.html`＝ヘッダー・フッター共通、`pages/*.html`＝各ページの本文、`decks.js`＝デッキのデータ、`assets/`、`img/decks/`）
- `build.py` … `src/` から公開用の `docs/` を作る。`python3 build.py <chars.json>`
- `docs/` … 公開されるファイル（自動で作るので手で直さない）

## よく変える設定（build.py の上のほう）
- `SITE_URL` / `CUSTOM_DOMAIN` … 独自ドメインにしたら変える
- `ADSENSE_CLIENT` … AdSense の `ca-pub-…`。入れると全ページに審査用コードと `ads.txt` が入る
- `AD_SLOT` … 広告ユニットの番号。入れるとトップ（ツールの下）とデッキページ（一覧の下）に広告枠が出る
- `CONTACT_FORM` … Googleフォームの URL

## デッキを追加するとき
`src/decks.js` に1件足し、画像（jpg）を `src/img/decks/` に置いて `build.py` を実行。
キャラを追加したら pawa-data の `chars.json` を使って `build.py` を実行し直す（`docs/data/chars.json` が更新される）。

## デッキページのレイアウト規則（新しいデッキを足すときもこれに合わせる）
デッキの追加手順は上の「デッキを追加するとき」。見た目は次のルールで統一しているので、画像を作る・データを書くときに守る。

**画像（src/img/decks/ に jpg で置く。選手名・ゲーム内の名前は必ず除く）**
- 育成結果 `r`：484×104。ランクアイコン＋ポジション帯＋総経験点だけ。黄色の縁取りは付けない（アンドロメダ学園と同じサイズ・見た目）。
- メインデッキ `d`：6人分を横一列。名前は入れない。
- サポートデッキ `s`：3人分。表示幅は CSS で「メインデッキの0.575倍」に固定してあり、アイコンの大きさがメインより大きくならない（`.subdeck`）。切り抜きはメイン画像と同じ縮尺で、横幅は約385pxを目安にする。
- 基礎上限 `u`：投手デッキは球速・コントロール・スタミナの3種だけを切り抜く（`.baseimg.half`で半分の幅で表示）。野手デッキは6種。

**表の表記（投手デッキ＝roman。deck.js が自動で行うので decks.js には略称を書かない）**
- 得意練習は略称：球速＝球、コントロール＝コン、スタミナ＝スタ、変化球＝変、守備＝守、メンタル＝メン。
- 「タッグボーナス」は「タッグ」と表示する（横スクロールなしで練習効果とタッグが見えるようにするため）。
- サポートデッキの表に「基礎上限」欄。球速・コン・スタの3種だけを「コン+8」の形で表示し、複数あれば2行。ミート・パワー・走力・肩力・守備力・捕球は表示しない。

**デッキのデータ（decks.js）**
- 育成のポイントは `tips`（箇条書き）、動画は `video`（YouTubeのID）。動画に注記が必要なときは `videoNote`（「※」は自動で付く）。
- キャラ検索は、名前・読み仮名・二つ名の読み仮名のどれでも一致する（chars.json の「読み」「二つ名読み」）。
- 公開用リポジトリでは、コミット作者を noreply にし、コミット文・PR・サイトに本名や呼び名を書かない（公開名は「りょーつー」）。
