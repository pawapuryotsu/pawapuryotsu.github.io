データの出どころと更新について

データの出どころ

当サイトのイベキャラの数値（練習効果、ボーナスなど）は、運営者がゲーム内の表示を確認して入力しています。デッキの編成と育成結果は、運営者が実際に育成した内容です。

更新について

ゲームのアップデートでキャラの性能や仕様が変わった場合は、確認でき次第、ページを更新します。更新した日は、トップページの「更新履歴」に載せます。すべての内容を最新の状態に保つことをお約束するものではありません。

誤りを見つけたら

数値や記載の間違いに気づいたら、お問い合わせフォームまたはX（@pawapuryotsu）からご連絡ください。確認のうえ、修正します。

掲載内容の位置づけ

掲載しているデッキは、運営者の育成の一例です。同じ編成でも、結果は運によって変わります。ご自身の判断でご活用ください。
