【評価基準】

  • 全員PSR50のボーナス想定
  • 練習効果アップとタッグボーナスの両方の値が高いほど高評価
  • 至高金特持ちは、至高獲得前提の評価とする
  • 高校キャラはメインデッキに1枚入れる想定の評価とする

【加点要素】

  • 至高金特を獲得可能
  • アイテム追加枠持ち
  • 練習改革持ち
  • 単練または二刀流練習
  • 球速、コントロール、スタミナ練習(スタミナボーナス有)
  • オリジナルストレートorオリジナル変化球持ち(オリジナルストレートの方がやや評価高い)
  • 体力回復&やる気回復イベント持ち
  • 特別なイベント持ち

【評価理由詳細】

ロマン開花學園では、種による練習経験点と開花試合の経験点の両方とも練習効果とタッグボーナスの数値で決まるため、2つのボーナスの高さが最重要です。

その上で、加点要素がどの程度あるかで評価を前後させています。(個人的主観アリ)

至高金特はオリジンランク6においては金特4個分の査定が付き大きなアドバンテージとなるため、練習効果とタッグボーナスが低くても評価を高く設定しています。

高校キャラはメインデッキに1枚入れる事で、セクション4でロマン開花學園と開花試合が可能になり、大幅経験点アップ&勝利の星を獲得出来るようになるため高評価としています。
