【評価基準】

  • 神崎こりすは無条件でSSランク確定(必須キャラ)
  • 全員PSR50のボーナス想定
  • コツイベントボーナスと試合経験点の両方の値が高いほど高評価(特にコツイベントボーナスが重要)
  • 至高金特持ちは、至高獲得前提の評価とする

【加点要素】

  • 至高金特を獲得可能
  • アイテム追加枠持ち
  • 練習改革持ち
  • 体力回復イベント持ち
  • 単練or二刀流練習

【評価理由詳細】

アンドロメダ学園では、高校所属キャラをメインデッキに入れるとオーバーフローゲージが増えた状態でサクセスが開始でき、彼女キャラをメインデッキに入れると高校金特獲得時の経験点がアップします。両方を1枠で満たせるのは神崎こりすのみで、必須キャラ扱いとしています。

コツイベントボーナスと試合経験点ボーナスが高いほど、VR練習の経験点が上がります。サクセスの約半分はVR練習を行うので非常に重要です。

至高金特はオリジンランク6においては金特4個分の査定が付き大きなアドバンテージとなるため、コツイベントボーナスと試合経験点ボーナスが多少低くても評価を高く設定しています。

その他、加点要素によって評価を前後させています。(個人的主観アリ)
