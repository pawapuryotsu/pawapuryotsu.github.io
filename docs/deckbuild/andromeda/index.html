重要な5点

このシナリオで重要となるのは主に5点です。

  • 神崎こりすをメインデッキに入れる
  • コツイベントボーナス
  • 試合経験点ボーナス
  • イベキャラの所持するブースターの種類
  • 練習改革

神崎こりすをメインデッキに入れる

まず、神崎こりすをメインデッキにセットしましょう。

高校キャラを1枚メインデッキにセットする事で、オーバーフローゲージが2本貯まった状態でスタート出来ます。高校キャラをセットしていない状態だと、サクセスが成り立たないレベルでマイナスです。

また、彼女キャラクターをデッキにセットする事で、高校金特を獲得した時の経験点が10000×4種から20000×4種にアップします。これが6回発生するので、合計24万点アップする事になります。

クリスマス・正月・バレンタインの体力回復も入って体力維持が格段にしやすくなり、彼女キャラの持つタッグボーナスセルも強力なため、彼女キャラも1枚必須になります。

神崎こりすは、高校キャラと彼女キャラの枠を1人でまかなえる唯一無二のキャラクターなので、必須キャラクターとなっています。

（必須なのに限定キャラなのはどういう事なのか問いたい）

コツイベントボーナスと試合経験点ボーナス

次に、コツイベントボーナスと試合経験点ボーナスが高いキャラを入れていきましょう。特にコツイベントボーナスの方が重要です。

コツイベントボーナスと試合経験点ボーナスが高いと、VR練習を行ったときの経験点が上がります。サクセスの半分はVR練習のターンになるので、目に見えて総経験点が変わります。

イベキャラのブースターの種類

そしてイベキャラのブースターの種類を意識しましょう。

査定の話になりますが、現在のオリジンランク6のサクセスでは、ポジション毎にオススメとなっている基礎能力（走力・肩力・守備力・捕球）を一点特化で上げた方が高ランクの選手を育成しやすいです。

  • 外野手…敏捷ブースター2枚で走力特化
  • 捕手・三塁手・遊撃手…精神ブースター0枚で肩力特化
  • 二塁手…筋力ブースター0枚で守備＆捕球特化

というのを意識すると、かなりサクセスをプレイしやすくなります。一塁手は、現状だと高ランクを作るのが一番難しいです。

練習改革

最後に練習改革ですが、余裕があれば片方は入れましょう。改革を入れる事で、その練習の経験点が稼ぎやすくなります。ただし、筋力練習をほとんど入れてない状態で筋力練習改革に枠を割くのはやや勿体ない気も。

走塁練習キャラが多い環境なので、走塁練習改革だけは入れるという事が多いです。
