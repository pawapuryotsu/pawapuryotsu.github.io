パワクエ超基本まとめ

パワクエを初めて遊ぶ人向けに、コレだけやればOK！という内容をまとめました。

もくじ
  1. 超基本的な流れ
  2. サクサク進めるためのポイント

超基本的な流れ

  1. マップを1マスずつ進みます。移動に1ターン使います。ターンが0になるとゲームオーバーなので、0になる前にゴールマス手前のボス戦マスにたどり着きましょう。
  2. ゴールマス手前のボス戦マスに勝つと次のエリアへ進み、負けるとゲームオーバーです。試合に勝つには、キー能力を上げるのが重要になります。

    このままだと敗北濃厚なので寄り道してチームを強化してから挑もう

  3. エリアが変わるたびにターンが7回復します。最後のエリアのボス戦に勝つとクエストクリアです。
  4. クリア、またはゲームオーバーになると、途中で拾ったアイテムを持ち帰る事が出来ます。途中であきらめるとアイテムを持ち帰れないので注意。

サクサク進めるためのポイント

  1. 道中の袋は極力拾って進めましょう。アイテムを沢山集めることで攻略しやすくなります。
  2. コーチ人数+〇のスキルが付いた契約書を集めて、デッキにセットしましょう。サクセスで育てた選手をコーチに付ける事ができ、大幅に戦力アップ可能です。
  3. 交渉の指輪をゲットして、デッキにセットしましょう。交渉術のスキルがあると、スカウトマスで2人目のスカウトが可能になり、チーム強化がしやすくなります。

    稀に交渉術3が付く。交渉術1より高確率で2人スカウトする事が出来る！
