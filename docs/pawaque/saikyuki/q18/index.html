主にドロップするアイテム

※11/24記事修正

エリア1で神前試合が2マスあり、エリア3で祈願もあるので、神前試合で入手できる別バージョン契約書のコーチ+4厳選向きのクエストです。

エリア2と3のボスドロップは微妙なので、エリア1ボス勝利まで行い、目当てのものが出なかったら諦めるエリア1厳選がおすすめです。

道中袋ドロップから[恋のキューピッド]天音姫恋の契約書がたまにドロップしたり、ボス勝利で西球記専用アイテムがたまにドロップするので、⑫旅は続く よりも副産物に恵まれています。

また、エリア1のボス勝利で潮来美霊の契約書・D:LIVEの契約書のドロップを確認しています。潮来美霊とD:LIVEはコラボキャラを除くと最強の契約書となっています。ただしコーチ+4を狙うのは非常に難しいため、これらのコーチ+4を狙うのはやり込み勢向けと言えるでしょう。
