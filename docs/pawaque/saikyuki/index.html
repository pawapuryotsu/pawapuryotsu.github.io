西球記とは

「西球記（さいきゅうき）」は、パワクエの5つ目のストーリーです。2026/11/16 14時に配信されました。

最新の掲載状況

  • クエスト一覧：①〜⑳・むずクエ・むちゃクエを載せています。
  • 神前試合まとめ：38校を載せています。
  • ミッション報酬まとめ：西球記の105件を載せています。

遊んで分かったことから順に追記します。

  • 良牙チーム（※11/26まで）

クエストのポイント

  • ③ハッカイ：このクエストから仙術・神前試合解禁
  • ④ゴジョー：エリア3グッドゴールにて交渉の指輪が高確率でドロップします。
  • ④ゴジョー：⑪で入手した袋ノ書で使える「袋変換の術」の仙術を使って、交渉術3が付いた銀・金レアリティの交渉の指輪を厳選するのに向いています。
  • ⑦ひょうたんの中：管理人はエリア2で払拭のお札が初めてドロップしました。
  • ⑪決戦のとき：エリア1クリアで、袋ノ書が実践上確定でドロップします。
  • ⑪決戦のとき：仙術「袋変換の術」を使って、銀・金レアリティかつ、優秀なスキルが付いた袋ノ書を厳選するのに向いています。
  • ⑪決戦のとき：スキルの狙い目は、「ターンアップ」「〇カード特殊能力」などです。
  • ⑪決戦のとき：実践上、ここでドロップする袋ノ書には西球記専用スキル(祈願率UPなど)は追加で付かないようです。付いた方いたらXなどで教えて頂けると幸いです。
  • ⑫旅は続く：管理人はここで初めてリュック+がドロップしました。
  • ⑲道中3：ボスドロップだけでなく、道中の袋からも西球記専用アイテムがドロップします。
  • ⑲道中3：専用アイテムを祈願する事も出来るうえ、ゴールまでの距離もそれほど長くないので、専用アイテムの周回はここがおすすめです。
