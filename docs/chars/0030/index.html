[最終兵器]虹谷誠の評価

SSロマン開花學園 11月ランキング【評価日2026/11/07】

【長所】

・11月現在、至高のスターターを獲得出来る中で唯一の練習効果30%持ち。

・コントロールコツを所持しており、オリジン6先発育成で超強力。所持コツも少ないため現実的なレベルでコツを狙う事が出来る。

・Lv35の時点でロマン開花學園に必要なボーナスが揃っている。

(上限開放やPSR覚醒でタッグボーナス伸びるけれど150%以下なのは変わらないのでギミック的には変化なし)

【短所】

・コントロールコツが取れるか取れないかでサクセスの結果が大幅に変わる。虹谷を使う場合はコツ厳選必須。

・中継ぎ抑え育成時は長所がほぼ活きないので他のキャラを使いたい。

【記入日2026/11/08】
