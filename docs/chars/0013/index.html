曙緋緒の評価

SSアンドロメダ学園 11月ランキング【評価日2026/11/09】
SS次期野手シナリオ有能キャラ予想【評価日2026/11/11】

【長所】

・PSR50時、コツボナ260%と非常に高い。試合経験点も30%と高水準。

・アンドロメダ学園において、強化マス増加セルという特別なセルを持つ。セルブースターを強化マスに組み込みやすくなり、非常に立ち回りやすくなる。

・基礎ボーナス30あり、次期野手環境での活躍も期待できる。

【短所】

・PSR50未満だとコツイベントボーナスが40%も下がる。PSR50を持っていなければフレンド枠で借りたい筆頭キャラである。
