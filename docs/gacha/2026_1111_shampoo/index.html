計算のしかた（注意）

  • 上限開放の合成ルールは上限開放のルールのとおりです。
  • 合成の順番は、手持ちのPSR・SR・PR・Rのシャンプーを見て、完成する確率が一番高くなる順番を全パターン調べて選んでいます。1枚ずつそのまま合成するか、素材を育ててから合成するかは、手持ちの枚数とあと何段階で完成かによって変わるため、決まった順番はありません。
  • 引き終わってから、まとめて合成した場合の確率です。
  • 上限開放済みのカードは、同じレアリティで同時に1枚だけ育てる前提です。
  • このガチャで出たシャンプーだけで計算しています（すでに持っている分は入れていません）。
  • 1ランク下の+5を素材にしたときの「45%で+2」は推測値です（ゲーム内で確認できないため、運営者の過去の調査によるおおよその値）。
  • 結果は確率なので、表の周回数を引いても完成しないことがあります。
